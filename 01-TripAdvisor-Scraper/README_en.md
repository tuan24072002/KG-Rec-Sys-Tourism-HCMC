# 01 TripAdvisor Scraper
This module contains the code for scraping tourist information from TripAdvisor. 

## Introduction

It consists of several Python scripts:

### 1. MySpider.py

This script defines a `Spider` class that is responsible for fetching HTML content from URLs using Selenium WebDriver (via `undetected-chromedriver`). It utilizes a random User-Agent for each request to mimic different browsers and includes mechanisms to detect IP blocks and CAPTCHAs.

### 2. PoiUrlScraper.py

This script contains the `PoiUrlScraper` class, which is used to extract URLs of points of interest (POIs) from TripAdvisor's listing pages. It retrieves the listing pages for attractions in Ho Chi Minh City, parses the HTML content to extract the URLs of individual POI detail pages, and also extracts their primary categories from the listing card. 

The URLs are saved to `output/poi_urls.txt`, and the category mappings are saved to `output/poi_categories.json`.

### 3. PoiInfoScraper.py

The `PoiInfoScraper` class defined in this script is responsible for scraping detailed information about each POI from its respective detail page. It utilizes the `Spider` class to fetch the HTML content of each page and parses it. 

To bypass TripAdvisor's dynamic loading, it reads the category mapping from `output/poi_categories.json` to populate the `type` column. It also applies robust filtering to keep the `description` column empty if no official static description exists (cleaning out AI reviews and template SEO boilerplates).

The extracted data is stored in a CSV file `output/poi_info.csv`.

### 4. ReviewScraper.py

This script implements the `ReviewScraper` class, which is used to scrape reviews for each POI from TripAdvisor. It first retrieves the URLs of reviews for each POI and then extracts relevant information such as the reviewer's username, location, review title, date, rating, user group, and review content. The scraped data is saved in a CSV file `output/reviews.csv` for further analysis.

This script relies on the output csv file generated by `PoiInfoScraper.py`.

## Execution Workflow and Usage

To run the TripAdvisor scraper module, follow these steps:

### Step 1: Prepare Directories
Ensure that the `html` and `output` directories exist inside `01-TripAdvisor-Scraper`:
```bash
mkdir html
mkdir output
```

### Step 2: Extract POI URLs and Categories
Run the script to collect listing attraction URLs and map them to their category:
```bash
python PoiUrlScraper.py
```
Outputs: `output/poi_urls.txt` and `output/poi_categories.json`.

### Step 3: Scrape Detailed POI Information
Run the script to scrape individual attraction details:
```bash
python PoiInfoScraper.py
```
Output: `output/poi_info.csv`.

### Step 4: Scrape User Reviews
Run the script to scrape user reviews for the collected attractions:
```bash
python ReviewScraper.py
```
Output: `output/reviews.csv`.
